# 香港房贷及持有成本计算器

独立静态网页，不需要安装依赖。打开 `index.html` 即可使用。

## 计算规则

- 总贷款上限按成交价与银行估价较低者的 90% 计算。
- 第一层贷款上限为 120 个月基本薪金，且不超过 HK$20,000,000。
- 第一层首 HK$10,000,000 年利率为 `max(P - 4.75%, 0.8%)`；其后部分最低 1%。
- 第二层年利率为 `P - 2.5%`，贷款额不超过第一层。
- 每月总债务不超过核实收入的 50%。
- 第一层优先使用，第二层贷款金额由用户直接设置。
- 默认启用贷款上限保护：第二层目标超过 DSR、物业按揭成数或计划上限时自动调整到可贷范围。
- 住宅从价印花税使用香港税务局 2026-02-26 起生效的税率表。

差饷、地租、管理费、装修费、律师费、中介佣金及按揭保险都是预算输入，用户可按实际报价修改。

## 测试

```powershell
node calculator.test.js
```
